# Research

This directory holds the study behind the docs, and none of it is published to the site. Each note describes chant and knr-ops as they were on 2026-09-20 and says plainly what exists and what is proposed.

`../docs/` explains how the kit works, and `../ROADMAP.md` lists what has to be built. The reasoning and the evidence are here.

| File | Contents |
|---|---|
| `00-principles.md` | The drop test, why typing adds no abstraction, and the konflate acceptance test |
| `01-knr-ops.md` | knr-ops as studied, at commit `f6b8d34` |
| `02-chant-model.md` | The parts of chant the kit uses, with doc paths |
| `03-placement.md` | Why knr-ops is a kit and why kind and Zarf are lexicons |
| `04-k8s-additions.md` | Proposed additions to chant's Kubernetes lexicon |
| `05-kit-design.md` | The kit's layout, configuration, Ops and adoption levels |
| `06-gaps-and-open-questions.md` | The four gaps found in chant, with file and line |
| `07-features.md` | Each feature, its reason and its status on the study date |
| `08-evidence.md` | How each claim was checked, and what was left unchecked |
| `09-fountain-and-ci.md` | The fountain lexicon, the steward, `ConvergeOp`, and the CI pipelines |

`../ROADMAP.md` supersedes the status columns and question lists in these files. Where the two disagree, the roadmap is current.

The files refer to the project as "the kit" and to its old working name, knr-chant. The repository is now knr-ops-kit.
